このドキュメントは、本プロジェクトの最終目的である「結晶・分子の対称性を題材にしたパズル」の構想を記録するものです。現在は回転軸クイズと操作あてクイズが実装済みなので、実装仕様は `docs/PUZZLE_SPEC.md` を優先します。このファイルは、今後の問題タイプ（○×、要素探索、合成など）を考えるための構想メモとして残します。

## 0. 全体のねらい

対称操作の本質＝**「動かしても同じに見える操作」**を、中学生でも体感できるパズルにする。

- 主対象は **分子（点群）から開始**。E・Cₙ・σ・i・Sₙ だけで、すべて「その場で動かして同じに見えるか」で説明できる。
- **結晶（空間群）は応用編**。並進・グライド・らせんなど「ずらす」系は中学生には直感的でないため後回し。
- パズルの主表記は後述の「初学者向け表記」。直感性を最優先する。

---

## 1. 表記方針（決定済み）

操作の表記は2系統を用意する。

### 1.1 初学者向け（直感・パズルの主表記）

形式：**動作アイコン + 動作名 + 色の基準 + 角度**

| 操作 | 表記例 | 補足（小さく添える） |
|---|---|---|
| E | ⊙ そのまま | 動かさない |
| Cₙ | ↻ 回す：**赤の軸**で 120° | 3回で1周 |
| σ | 🪞 鏡うつし：**青い鏡** | — |
| i | ✦ 点対称：中心で反対へ | — |
| Sₙ | ↻🪞 回して鏡うつし：90° | 回してから鏡 |

決定した方針:
- **回転の量は「角度」を主に**（`120°`）。回数（3回で1周）は補助で添える。`C₃` のような記号は使わない。
- **軸・面は記号や座標でなく「色」で指す**（「赤の軸」「青い鏡」）。miller 指数・xyz 座標は一切出さない。
- **回転方向を矢印で示す**（↻ 時計回り / ↺ 反時計回り）。合成パズルで「進む/戻す」を直感化するため。

### 1.2 専門家向け（厳格・Schoenflies）

化学の標準表記。軸・面の向きを添える。

```
E
C₃¹ (主軸 z)      ← 上付きで何回目かを明示
C₂ (z軸)
σᵥ(xz)           ← 面の向きを括弧で
σₕ
S₄¹ (z軸)
i
```

- Cₙ・Sₙ は上付きで累乗（C₃¹, C₃²）を付け、合成で「何回分か」を一意にする。
- 軸・面は分子に固定した座標（主軸を z）で表す。
- σ は v/h/d（主軸に対し垂直/平行/対角）を区別。

## 2. 実装の前提：対称要素ごとの固定色

色で基準を指す方式の前提として、**「操作リストの色」と「3Dビューの軸・面の色」が必ず一致**している必要がある。崩れると表記が意味をなさない。

要件:
1. **対称要素（軸・面・中心）ごとに固定の色を割り当てる**（操作ごとではなく要素ごと。同じ軸を使う複数操作は同じ色）。
2. 操作を選ぶと、その色の軸/面が 3D で光る／強調される。
3. 識別しやすい固定パレット（赤・青・緑・橙…）。高対称分子で要素数が色数を超える場合は**番号を補助**（例「赤の軸①」）。

この固定色仕様はパズル全体の土台になるため、パズル実装の前に詰めておくべき。

## 3. パズル本体：構造を見て対称性を当てる

### 3.1 基本コンセプト

構造（分子/結晶）を表示し、システムが対称要素（面・軸など）だけを強調表示する。生徒は「その要素にどんな対称性があるか」「本物の対称性か」を判定する。

### 3.2 設計上の注意（重要）

- **面を強調すると答えがほぼ自明**（面＝鏡映 σ 一択）になり、パズルにならない。
- **1本の軸には複数の操作が同居する**（C₆軸はC₃・C₂も含む、C₄軸はS₄も同居）。「この軸の対称性は？」だと正解が一意に決まらず採点が曖昧。
- 「何回回転軸か（2/3/4/6）」は軸の線だけ見ても分からず、**分子の形を見て考える**必要がある。

→ 対策として「要素を見て名前を当てる（抽象）」より、**「操作を試して同じに見えるか確かめる（具体）」をパズルの軸**にする。アニメーションで「動かす→重なる」を体感させるのが中学生には最も効く。

### 3.3 難易度のはしご

**レベル1：○×（いちばん易しい）**
強調された面/軸で操作を**実際にアニメーション再生**し、「動かす前と同じに見えた？ これは本物の対称性？」を○×で答える。偽の要素（少しずれた鏡など）も混ぜると良問になる。

**レベル2：何回回転軸か（選択）**
軸を強調し「この軸は何回回すと元に戻る？ 2/3/4/6」。各候補を**試し回し**でき、当たれば構造がピタッと重なる。角度主表記（120°など）と対応。

**レベル3：探して数える（いちばん難しい）**
「この分子の鏡を**全部見つけよう**」。生徒が面/軸を置く・選ぶ→システムが正誤判定。対称要素の数＝点群の理解に直結。

## 4. 発展パズル：閉包と合成

レベル3の延長として、点群の構造そのものを扱う。

### 4.1 閉包を見つける

その構造が持つ対称操作を**すべて見つけ終える**（＝点群の対称操作の集合＝閉じた集合を完成させる）。「もう新しい操作は出てこない」状態まで到達することで、点群が**閉じている**ことを体感する。

### 4.2 操作の合成パズル

閉包を見つけた後、「**このような操作は、今見つけた操作をどう組み合わせれば作れるか**」を問う。

- 例：「赤の軸で120°回す」を2回続けると「240°回す」になる。
- 例：「鏡うつし」と「回転」を組み合わせると別の鏡や回映になる。
- システムは合成結果（W,t の合成）を計算し、既存操作のどれと一致するか判定する基盤が既にある（`crystal_viewer/symmetry_operations.py` の合成・BFS 探索、custom operation sequence 機能）。
- 回転方向の矢印（↻/↺）が「進む/戻す」の直感に効く。

このパズルは「対称操作の集合が群をなす（合成について閉じている・逆元がある）」という群論の入口を、記号でなく**操作の組み合わせ遊び**として体験させるのがねらい。

## 5. 実装順序の方針（履歴）

当初案は以下。現在は、1の固定色を作り込まずに既存の強調表示を使い、回転軸クイズと操作あてクイズから先に実装した。

1. **対称要素ごとの固定色**（§2）— パズル全体の土台。
2. **レベル1（○×＋アニメ）**（§3.3）— 最小で価値を確認できる。
3. レベル2 → レベル3 → 発展（閉包・合成）（§3.3, §4）。
4. 分子で一通り完成させてから結晶へ拡張。

### 現時点で先に必要な土台作業（パズルの前段階）

- UI 整備（初学者モード／多機能モードの切り分け構想あり。Element 表示は将来の多機能モード側で活用予定）。
- web と PyVista で分割されている表示・操作の統一。

これらが整ってからパズル本体に着手する。
