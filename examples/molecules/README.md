# Molecule XYZ Samples

Idealized XYZ structures for testing molecular symmetry display.

| File | Expected symmetry |
| --- | --- |
| `water.xyz` | C2v |
| `ammonia.xyz` | C3v |
| `methane.xyz` | Td |
| `carbon_dioxide.xyz` | D*h / linear |
| `boron_trifluoride.xyz` | D3h |
| `ethene.xyz` | D2h |
| `allene.xyz` | D2d |
| `benzene.xyz` | D6h |
| `xenon_tetrafluoride.xyz` | D4h |
| `sulfur_hexafluoride.xyz` | Oh |

These are compact, idealized coordinates for viewer and operation-list checks, not optimized geometries.
